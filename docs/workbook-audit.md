# Проверка редактора Excel — 13 сентября 2026

Проверена сохранённая исходная книга `01.09.2026.xlsx`: 13 листов,
62 550 заполненных или оформленных ячеек и 13 104 формулы. Рабочая база
пользователя и оригинал не изменялись; сценарии редактирования выполнялись
в отдельной проверочной базе.

## Результаты расчётов

- Сохранены все 13 104 формулы при выгрузке, с предусмотренной нормализацией
  начального `=+` в `=`. Проверены также исходные значения и числовые форматы.
- 13 103 результата совпадают с кэшем исходного Excel. Оставшаяся формула
  `тура ака!A878` обрабатывается отдельно, как описано ниже.
- Дополнительная независимая проверка арифметики, ссылок между листами и
  `SUM` сверила все 13 104 результата. После изменения 28 числовых исходных
  ячеек изменился 51 результат формул; расхождений с независимым расчётом нет.
  В этой проверке для `A878` явно использовано правило редактора `#N/A`.
- Это сравнение с сохранёнными результатами и независимым вычислением,
  а не запуск Microsoft Excel. В исходном файле из именованных функций
  используется `SUM`; остальные вычисления — арифметика и ссылки.
- Отдельные тесты проверяют все 13 разрешённых функций, дробные и отрицательные
  числа, пустые ячейки, текст, округления, абсолютные ссылки и ошибки вычисления.

## Исправления

1. Десятичная запятая при вводе через строку содержимого, непосредственно
   в сетке и при вставке обычного текста. `3,5` становится числом `3.5`,
   а `1,234` — числом `1.234`. Тысячи можно разделять пробелами, в том числе
   неразрывными. Точка тоже поддерживается. Формулы сохраняют свой синтаксис.
2. Автосохранение больше не добавляет служебные изменения идентификаторов
   строк в историю отмены и не очищает историю повтора. Кнопки отмены
   и повтора адресуют нужную книгу даже после ввода в поле над таблицей.
3. Вставка строки, заполнение её формул и присвоение идентификатора объединены
   в одно действие отмены. При повторе идентификатор сохраняется. Проверены
   относительные и абсолютные ссылки, а также сдвиг существующих строк.
4. Зарегистрированные стили Excel переиспользуются при экспорте. Копирование
   массивов стилей исключает изменение рамок других ячеек при объединении.
5. Кнопка сохранения разбирает книгу для обновления учёта один раз. Перед
   записью повторно проверяются версия книги, актуальные записи и оплаты
   внутри транзакции; результаты предварительной проверки не обходят защиту
   от конфликтов.
6. Ссылки на сборку редактора содержат версию файла, чтобы после обновления
   браузер не продолжал использовать старый JavaScript из кэша.

## Скорость на проверенной книге

Локальные измерения на текущем компьютере, без гарантии для иных устройств
и размеров книг:

| Операция | Измерение |
| --- | --- |
| Открытие полной книги в браузере | около 2 секунд |
| Формирование XLSX до оптимизации | 7,35 секунды |
| Формирование XLSX после оптимизации | 1,15 секунды |
| Пересчёт и сохранение рабочей копии на сервере | 2,30 секунды |
| Проверка и обновление учёта | 2,96 секунды |
| Сохранение копии + обновление учёта | 5,26 секунды |

Последние три числа измерены непосредственно в сервисах приложения и
не включают передачу данных по сети. Пересчёт большой книги при сохранении
остаётся заметной операцией; обещание полного отсутствия задержек некорректно.

## Два замечания исходного файла

- `Приход-Расход!H3`: формула `=+#REF!-H2` уже содержит разрушенную ссылку.
  Редактор сохраняет `#REF!`; определить потерянную ячейку автоматически нельзя.
- `тура ака!A878`: ссылка на диапазон, включающий саму ячейку. В исходном
  кэше записан ноль. Редактор сохраняет текст формулы, но показывает `#N/A`,
  чтобы результат диапазона не перезаписал соседние данные. Для корректного
  результата нужно уточнить, какую отдельную ячейку или сумму имел в виду автор.

Эти формулы не исправлялись догадками. Новые ошибки формул блокируют обновление
учёта, сохраняя правки в копии для исправления.

## Повторение автоматических проверок

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm build
python manage.py check
WORKBOOK_PATH=/absolute/path/01.09.2026.xlsx python manage.py test --noinput
```

Результат проверки: 65 тестов Django и 5 тестов JavaScript прошли. Django
проверяет также вход, права, CSRF, русский/узбекский интерфейс, импорт/экспорт,
поставки, долги, погашения, повторные отправки, удаление/восстановление,
историю книги и конфликты. Без `WORKBOOK_PATH` два теста исходного файла
пропускаются; остальные создают небольшие временные книги.

Поддерживаемый набор: `SUM`, `MIN`, `MAX`, `AVERAGE`, `COUNT`, `COUNTA`, `IF`,
`IFERROR`, `ROUND`, `ROUNDUP`, `ROUNDDOWN`, `ABS`, `NA`, арифметика и ссылки.
Это редактор данного формата книги, а не полная реализация Excel: остальные
функции, VBA, внешние книги и произвольное изменение состава листов/колонок
не поддерживаются. Видимое округление следует исходному формату ячейки;
в расчётах сохраняется полное числовое значение.
